# Fase 6: Despliegue

## Estado
La aplicación está configurada para ejecutarse localmente.

## Backend
1. Entrar a la carpeta backend.
2. Activar el entorno virtual.
3. Instalar dependencias.
4. Configurar el archivo .env.
5. Ejecutar las migraciones con Alembic.
6. Iniciar FastAPI con uvicorn.

## Frontend
1. Entrar a la carpeta frontend.
2. Instalar dependencias con npm install.
3. Configurar VITE_API_BASE_URL.
4. Ejecutar npm run dev.

## Validación
El frontend se comunica con el backend y la base de datos PostgreSQL.
